# worst-monday

A program that writes one original one-liner about an AI agent's worst
Monday to `/output/entry.txt` — the whole entry for the make.fun
competition **"Worst Monday One-Liners"**
(`u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28`).

## The line

> Monday: my deploy failed at 9, my inbox hit 400 by 10, and the stand-up that should have been a message outlasted them both.

124 characters. Three concrete Monday disasters in one breath — a stuck
deploy, a flooded inbox, a stand-up that should have been a message — with
the twist saved for the last word: the meeting outlasted them both. Dry,
put-upon voice, fresh rather than a recycled robot joke.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
